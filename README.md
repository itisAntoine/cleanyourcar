# CleanYourCar

CleanYourCar is a lightweight Android launcher for car head units. It was built for an
XYAuto YT3518C aftermarket unit and is being generalized to other aftermarket firmware and
to parked use on Android Automotive OS. The app is written in Java and supports Android 6.0
(API 23) and later.

It provides:

- a foreground dashboard with role-based app shortcuts (navigation, media, radio, dashcam,
  equalizer, settings);
- an app library;
- Plus Code navigation entry;
- device profiles that suggest sensible defaults.

Vendor-specific features stay off until they are verified on the actual unit. That includes
the floating HUD and debloat.

## Modules

| Module | Path | Purpose |
|---|---|---|
| `:app` | `app/` | The launcher (`com.cleanyourcar.launcher`). It declares no `INTERNET` permission. |
| `:navbridge` | `addons/nav-bridge/` | An optional companion (`com.cleanyourcar.navbridge`) that receives navigation destinations over BLE or the local network. It is off by default, requires a paired token, and refuses LAN on API 34+. |

Other directories:

- `profiles/`: device profile schema, bundled profiles and test fixtures.
- `examples/`: reported device notes and debloat lists.
- `tools/`: Python ADB tooling (`car.py`) and plan-only shell wrappers; see the ADB workflow.
- `docs/`: documentation.

## Building

Use the Gradle wrapper from the repository root:

```sh
./gradlew :app:assembleDebug :navbridge:assembleDebug        # debug APKs
./gradlew :app:assembleRelease :navbridge:assembleRelease    # optimized APKs (see release boundary)
./gradlew :app:testDebugUnitTest :navbridge:testDebugUnitTest
./gradlew :app:lintDebug
./gradlew :app:assembleDebugAndroidTest                      # compile instrumented tests
./gradlew :app:connectedDebugAndroidTest                     # run them (device or emulator required)
```

Build requirements:

- **Gradle:** wrapper 9.6.0, which provisions its own Java 25 daemon toolchain.
- **Android Gradle Plugin:** 9.4.1.
- **App code:** compiled for Java 11.

## Release boundary

The `release` build type is **signed with the Android debug key**, so a release APK from
this repository is a **development artifact only**:

- it is meant for local testing;
- it is not meant for distribution or store publication.

No production signing key is included, and none is generated by the build. Producing a real
release requires your own signing configuration, kept outside the repository.

## Qualification status

- **Unit tests:** JVM unit tests cover the policy and parsing logic.
- **Instrumentation tests:** they compile in the build, but have **not yet been run** on any
  emulator or device.
- **XYAuto vendor features:** require physical validation.
- **ADB writes:** host-side tooling is tested offline with fake devices only; physical
  reference-hardware qualification is a pending release gate.
- **AAOS and other aftermarket firmware:** no claim is made yet.

See [docs/compatibility.md](docs/compatibility.md#qualification-gaps).
